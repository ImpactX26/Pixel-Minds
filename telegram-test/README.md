# PixelMind AI — Telegram Integration (Communication Test)

> **Role:** Member 4 – AI + Communication Integrations  
> **Status:** Phase 1 — Telegram Communication Test (Minimal Working Version)

This is the initial, modular Telegram communication service for **PixelMind AI**. Its sole purpose right now is to verify end-to-end message reception and response delivery via Telegram's official Bot API and webhooks without any heavy dependencies or premature complexity.

---

## Architecture Flow

```text
Telegram User
    ↓ (Types a message)
Telegram Cloud Servers
    ↓ (Pushes HTTPS POST update)
Public HTTPS Tunnel (ngrok / Cloudflare Tunnel)
    ↓ (Forwards traffic)
Local Express Backend (http://localhost:3000)
    ↓
POST /api/telegram/webhook (TelegramController)
    ↓
TelegramService (Extracts User ID, Chat ID, Username, Text)
    ↓
Evaluates Test Rules ("Hello", "What is PixelMind AI?", or Echo)
    ↓
POST https://api.telegram.org/bot<TOKEN>/sendMessage
    ↓
Telegram Cloud Servers
    ↓
Telegram User (Receives bot response in chat)
```

## 1. Requirements

Before running this project, ensure you have:
- **Node.js** (v18.0.0 or higher, recommended v20+ or v24)
- **npm** (comes with Node.js)
- A **Telegram account** (on mobile or desktop)
- A tunneling tool: **ngrok** ([ngrok.com](https://ngrok.com)) or **Cloudflare Tunnel** (`cloudflared`) to expose `localhost:3000` over public HTTPS.

## 3. How to Create the Telegram Bot Using BotFather

If you haven't created your bot yet, follow these simple steps in Telegram:

1. Open Telegram and search for **`@BotFather`** (ensure it has the blue verified checkmark).
2. Click **Start** or send the command:
   ```text
   /newbot
   ```
3. BotFather will ask for a **Display Name** for your bot.  
   *Example:* `PixelMind AI Test`
4. BotFather will then ask for a **Username** (must end in `bot`).  
   *Example:* `PixelMindAITestBot` or `pixelmind_test_bot`
5. Once created, BotFather will send you a message containing your **HTTP API Token**.  
   It looks like this:
   ```text
   7123456789:AAFl4vEXAMPLE-Token_xyz987654321
   ```
   *⚠️ Keep this token secret! Never commit it to GitHub or share it publicly.*

---

## 4. Where to Put Your BOT Token

Open the file named **`.env`** inside the `telegram-test/` folder.

Paste your token after `TELEGRAM_BOT_TOKEN=`:

```env
TELEGRAM_BOT_TOKEN=7123456789:AAFl4vEXAMPLE-Token_xyz987654321
PORT=3000
WEBHOOK_DOMAIN=
```

> **Note:** `.env` is listed in `.gitignore`, so your token will never be committed to Git.

## 6. How to Expose Localhost to the Internet

Telegram requires a **public HTTPS URL** to send webhooks. Since your server is running on `localhost:3000`, use a tunnel:

### Option A: Using ngrok (Recommended)
1. Download ngrok from [ngrok.com](https://ngrok.com/download) or install via winget/scoop/choco.
2. In a separate terminal window, run:
   ```bash
   ngrok http 3000
   ```
3. Copy the **Forwarding HTTPS URL** generated by ngrok.  
   *Example:* `https://a1b2-34-56-78-90.ngrok-free.app`

### Option B: Using Cloudflare Tunnel (`cloudflared`)
1. Download `cloudflared` or run:
   ```bash
   cloudflared tunnel --url http://localhost:3000
   ```
2. Copy the generated `https://xxxx.trycloudflare.com` URL.

## 7. How to Set the Telegram Webhook

Once you have your public HTTPS tunnel URL (e.g., `https://a1b2-34-56-78-90.ngrok-free.app`), choose any of the 3 methods below to register it with Telegram:

### Method 1: Using the Built-in Script (Easiest)
Run this command from your terminal:
```bash
npm run webhook:set https://a1b2-34-56-78-90.ngrok-free.app
# OR:
npm.cmd run webhook:set https://a1b2-34-56-78-90.ngrok-free.app
```
*(You can also set `WEBHOOK_DOMAIN=https://a1b2-34-56-78-90.ngrok-free.app` in your `.env` and simply run `npm run webhook:set`)*.

### Method 2: Via Your Web Browser
Open your browser and paste this URL (replace with your actual token and ngrok domain):
```text
https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook?url=https://a1b2-34-56-78-90.ngrok-free.app/api/telegram/webhook
```
You should see:
```json
{
  "ok": true,
  "result": true,
  "description": "Webhook was set"
}
```

### Method 3: Using cURL
```bash
curl -X POST "https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook" -H "Content-Type: application/json" -d "{\"url\":\"https://a1b2-34-56-78-90.ngrok-free.app/api/telegram/webhook\"}"
```

### Verify Webhook Status anytime:
```bash
npm run webhook:get
# OR in browser:
https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getWebhookInfo
```

In later phases, the communication flow will be expanded seamlessly without having to rewrite this service:

```text
Current Testing Flow:
Telegram → Webhook Controller → TelegramService → Test Rules → Bot Response

Upcoming Phase 2 & 3:
Telegram
   ↓
Telegram Controller & Service (Extracts userId, text, metadata)
   ↓
AI Orchestrator / Agent Service (Member 4 - LLM / Conversational Engine)
   ↓
Applicant Journey / Next Best Action API (Member 3 - NestJS Backend)
   ↓
Response Generation
   ↓

   ↓
```

Because `TelegramService` is built as an independent, modular TypeScript class, it can be dropped directly into a NestJS provider or imported by any orchestrator when the team is ready for the next phase.
